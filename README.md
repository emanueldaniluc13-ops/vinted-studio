# Vinted Studio

Aplicación web local para preparar fotografías de prendas con una interfaz responsive.

## Ejecutar

1. Instala Node.js.
2. Ejecuta `npm start`.
3. Abre `http://localhost:3000`.

La clave de fal.ai debe mantenerse en el servidor mediante la variable `FAL_KEY`; nunca la incluyas en el navegador ni en el repositorio. La interfaz incluye persistencia local para productos y ajustes y una simulación visual de generación cuando todavía no hay endpoint de generación conectado.
